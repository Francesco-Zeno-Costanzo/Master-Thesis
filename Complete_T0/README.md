# Complete_T0

This directory contains the complete version of the code used for computing the EOS for cold matter.

np_matter.py: we compute the binding energy per nucleon in symmetric nuclear matter with the use of sigma-omega model
in relativistic mean field.

RMF_T_0.py: This code solves the equations of the relativistic mean field model.
Is possible to consider all coupling constants density-dependent or not
the values of the coupling constants are computed in compute_costants.py
